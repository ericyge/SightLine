Custom openWakeWord ONNX models and downloaded support models live here.
Set WAKE_MODEL_PATH=models/hey_sightline.onnx in the local .env for a custom model.
Run python -m audio_directions.setup_wake to download the stand-in and support models.
All binaries stay git-ignored. Pretrained wake models are CC BY-NC-SA 4.0;
custom model redistribution depends on the training assets and their licenses.
See ../README.md for installation, training, and licensing details.
